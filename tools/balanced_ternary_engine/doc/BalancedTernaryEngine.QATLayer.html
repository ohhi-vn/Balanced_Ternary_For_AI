    BalancedTernaryEngine.QATLayer (balanced_ternary_engine v0.1.0-dev)

    Copy Markdown

    Quantization-Aware Training layer with ternary weights.

    Maintains FP32 shadow weights that are ternarized on each forward pass. Uses a straight-through estimator (STE) so gradients flow to the shadow weights during training: the forward pass uses ternary weights, while the gradient is applied to the shadow weights directly.

    This module provides the primitives (ternarize, forward, update, freeze). The training loop composes these with a loss and an optimizer step.
