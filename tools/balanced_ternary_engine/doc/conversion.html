    Quick Path (PTQ)

    {:ok, summary} =

    arch: :llama,
    mode: :absmean
  )

    CLI

    ternary_converter convert --input model.safetensors --arch llama --mode absmean --output model.tbin

    Use --profile yolo|imagenet|llm for family-specific defaults.
