    BalancedTernaryEngine.RawLayer (balanced_ternary_engine v0.1.0-dev)

    Copy Markdown

    A dense weight matrix kept at half precision inside a converted model.

    Quantization-sensitive tensors — token embeddings, LM head, layer norms — are stored as RawLayer instead of being ternarized (see BalancedTernaryEngine.Architectures). Weights are held as raw float16 bytes; activations are computed in f32.

    forward_nx(layer, input)

    @spec forward_nx(t(), Nx.Tensor.t()) :: Nx.Tensor.t()

    Forward pass: dequantize to f32 and apply as a linear projection.

    Handles both (out, in) (y = x·Wᵀ) and (in, out) (y = x·W) layouts — GPT-2-style checkpoints store Conv1D weights transposed, and the converter preserves whichever layout it was given. Intended for lm_head-style tensors; embeddings and norm vectors are consumed by runtimes via to_tensor/1.
