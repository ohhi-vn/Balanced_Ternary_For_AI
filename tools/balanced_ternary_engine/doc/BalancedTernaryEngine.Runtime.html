    BalancedTernaryEngine.Runtime (balanced_ternary_engine v0.1.0-dev)

    Copy Markdown

    Minimal runtime for executing a converted .tbin model.

    Supports layer chaining, softmax, layer normalization, multi-head attention with a KV cache, and prefill/decode phases.
