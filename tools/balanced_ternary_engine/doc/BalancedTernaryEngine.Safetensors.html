    BalancedTernaryEngine.Safetensors (balanced_ternary_engine v0.1.0-dev)

    Copy Markdown

    Pure-Elixir reader/writer for the HuggingFace .safetensors format.

    Layout:

    [header_len: u64 little-endian][header: UTF-8 JSON][tensor data]

    Header JSON maps tensor names to %{"dtype" => ..., "shape" => [...], "data_offsets" => [begin, end]} where offsets are relative to the start of the data section. An optional __metadata__ key holds a string-to-string map.

    Float tensors are returned as :f32; integer tensors as :s64.

    decode(binary)

    @spec decode(binary()) :: {:ok, map(), map()} | {:error, term()}

    Decode safetensors from a binary.

    Any structural problem (truncated file, bad JSON, bad offsets) returns {:error, :invalid_safetensors}; an unknown dtype raises ArgumentError since it indicates a caller/producer bug rather than corrupt input.

  binary()

    Encode a map of tensors to safetensors binary.

    Supported tensor types are written as-is; anything else is converted to f32. Data blocks are padded to 8-byte alignment.

    read_sharded(path)

    Read a sharded safetensors model given a path to its index JSON file (model.safetensors.index.json) or a directory containing one.

    Resolves shard paths relative to the index file's directory, loads every shard, and merges their tensors into a single map.
