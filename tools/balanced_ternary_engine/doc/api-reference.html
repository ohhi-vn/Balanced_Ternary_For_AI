    Modules

    BalancedTernaryEngine

    Main API for converting pretrained models to balanced ternary format.

    BalancedTernaryEngine.Architectures

    Per-architecture mixed-precision policies for common model families.

    BalancedTernaryEngine.Benchmark

    Simple benchmarking helpers for conversion and runtime execution.

    BalancedTernaryEngine.CLI

    Command-line interface for the BalancedTernaryEngine tool.

    BalancedTernaryEngine.Exporter

    Exports and imports ternary models to/from .tbin binary format.

    BalancedTernaryEngine.Layer

    A neural network layer with ternary weights.

    BalancedTernaryEngine.Packer

    Packs ternary {-1, 0, +1} tensors into compact binary format.

    BalancedTernaryEngine.Pipeline

    End-to-end conversion: safetensors model → .tbin balanced ternary model.

    BalancedTernaryEngine.QATLayer

    Quantization-Aware Training layer with ternary weights.

    BalancedTernaryEngine.Quantizer

    Converts full-precision weight tensors to balanced ternary {-1, 0, +1}.

    BalancedTernaryEngine.RawLayer

    A dense weight matrix kept at half precision inside a converted model.

    BalancedTernaryEngine.Runtime

    Minimal runtime for executing a converted .tbin model.

    BalancedTernaryEngine.Safetensors

    Pure-Elixir reader/writer for the HuggingFace .safetensors format.

    BalancedTernaryEngine.Sensitivity

    Analyzes per-layer sensitivity to ternary quantization.

    BalancedTernaryEngine.Stats

    Aggregate statistics over a list of model layers.

    BalancedTernaryEngine.Validation

    Reusable validation helpers for tensors, configs, and model files.

    Mix Tasks

    mix analyze

    Analyze a .tbin model.

    mix convert

    Convert a pretrained model to balanced ternary format.

    mix infer

    Run inference on a .tbin model.
