# Proposal

## Why

The Elixir package and modules are named `TernaryConverter`, but the desired product name is `BalancedTernaryEngine`. Renaming aligns the codebase, docs, and published package identity.

## What Changes

- Rename the Mix app and Hex package to `balanced_ternary_engine`.
- Rename all `TernaryConverter.*` modules to `BalancedTernaryEngine.*`.
- Update tests, guides, README, and configuration references.
- No behavior or format changes.

## Capabilities

### New Capabilities

None (rename/refactor; no spec-level behavior changes).

### Modified Capabilities

None.

## Impact

- Affected files: all Elixir modules, tests, docs, and `mix.exs`.
- No `.tbin` format changes.
